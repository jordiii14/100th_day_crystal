100 DAYS — CRYSTAL
====================

This is a ready-to-upload static website.

QUICK START:
1. Open index.html to preview it in a browser.
2. Upload the entire folder to your website host.
3. Keep the images folder next to index.html.
4. No coding is required.

The 8 photos you uploaded are already included.
The site is mobile-first and works on phones and computers.

OPTIONAL MUSIC:
Put a file named music.mp3 in the main folder and replace the music button code later if you want audio.
